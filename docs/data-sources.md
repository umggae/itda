# 데이터 출처와 이용 조건 점검표

README "데이터 출처와 갱신일"을 쓸 때 쓰는 점검표입니다. 아래 "확인할 것"은 제가(AI) 단정하지 않은 부분이니, 각 약관 원문을 직접 읽고 README에 내 말로 적어 주세요.

모든 데이터는 **실시간 조회**입니다. 미리 저장해 둔 파일이 없으므로 "갱신일"은 조회한 시점입니다.

| 용도 | 출처 | 서버 함수 | 확인할 것 |
|---|---|---|---|
| 여행지·음식점 검색, 좌표, 쉬는 날·이용시간·주차·예약·문의처 | 한국관광공사 TourAPI (공공데이터포털, KorService2) | /api/search, /api/detail | 이용 허락 조건(공공누리 유형 등 — 응답의 `cpyrhtDivCd` 필드는 이미지 저작권 구분), 출처 표시 방법, 일일 호출 한도 |
| 출발지·도착지 검색(역·터미널·숙소 등) | 카카오 로컬 API (키워드 검색) | /api/search | 이용 약관, 출처 표시, 호출 한도 |
| 대중교통 이동시간·노선 | Google Routes API (경로 매트릭스, 경로) | /api/matrix, /api/leg | Google 지도 플랫폼 약관 — OpenStreetMap(Leaflet) 지도와 함께 쓰는 것, 결과 저장·캐시, 출처 표시 규정 / 요금과 무료 사용량 |
| 자동차 이동시간·거리 | 카카오모빌리티 길찾기 API | /api/matrix | 이용 약관, 호출 한도, 출처 표시 |
| 지도 | Leaflet + OpenStreetMap | (브라우저) | © OpenStreetMap 기여자 표기(화면 하단에 이미 있음), 타일 서버 이용 정책 |

## 알려진 한계에 적을 만한 것 (사실 확인된 것)
- 자동차 경로는 Google Routes API가 한국에서 경로를 반환하지 않아(2026-10-15 실제 호출로 확인) 카카오모빌리티를 씁니다.
- 대중교통 이동시간은 입력한 날짜·시작 시각 기준 시간표로 계산합니다. 한 번에 받는 이동시간표는 모든 구간을 같은 출발 시각으로 계산합니다. 경유 일정은 실제 시각이 조금씩 달라지므로, 화면에는 "정확히 몇 시 차" 대신 탑승 시간(승차~하차)과 배차 간격을 보여 줍니다.
- 배차 간격은 Google이 주는 `headway` 값으로, 조회한 시간대의 예상 간격입니다(하루 평균이 아님). 노선에 따라 값이 없을 수 있습니다.
- 대중교통은 오늘 기준 약 6일 전~99일 뒤 날짜만 조회됩니다.
- TourAPI 키워드 검색에는 모든 장소가 나오지 않을 수 있습니다(부산 시험 중 확인한 사례: "감천" 검색에 감천문화마을이 나오지 않음). 그래서 카카오 검색 결과를 함께 보여 줍니다.
- 카카오 장소(역·터미널·숙소 등)에는 쉬는 날·영업시간 정보가 없습니다.
- 서버 함수는 공개 주소라 누구나 호출할 수 있습니다. 비용 보호를 위해 입력 검증·캐시·장소 수 제한(출발지·도착지 포함 8곳)을 두었고, 호출 횟수 자체를 막는 제한은 없습니다.
