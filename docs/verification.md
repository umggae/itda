# 검증 기록

"입력 / 기대 결과"는 초안입니다. "실제 결과 / 판단 / 근거"는 직접 확인한 뒤 채워 주세요.

| 입력 | 기대 결과 | 실제 결과 | 판단 | 근거 |
|---|---|---|---|---|
| 장소 2곳, 09:00~21:00, 대중교통 | 구간별 이동시간과 장소별 도착·출발 시각 시간표가 표시된다 | | | |
| 종료 시각을 일부러 짧게(예: 11:00) 설정 | "불가능"과 초과 시간, 문제 구간이 표시된다 | | | |
| 순서가 비효율적인 장소 3곳 | 더 짧은 순서와 줄어드는 시간이 제안되고, "적용"/"유지"를 고를 수 있다 | | | |
| 이미 가장 짧은 순서 | 순서 제안이 나오지 않는다 | | | |
| 장소 0곳으로 검사 | 장소를 추가하라는 안내가 나온다 | | | |
| 시작 시각 22:00, 종료 시각 21:00 | 시각 오류 안내가 나온다 | | | |
| 출발지 비움 | 출발지 선택 안내가 나온다 | | | |
| 체류시간에 "abc" 입력 | 숫자(분)로 입력하라는 안내가 나온다 | | | |
| 장소 7곳째 추가 시도 | 하루 최대 6곳 안내가 나온다 | | | |
| 없는 장소명 검색 | "검색 결과 없음" 안내와 다음 행동이 나온다 | | | |
| 데이터 파일 불러오기 실패(파일 이름을 바꿔 시험) | 오류 안내와 다시 시도 방법이 나온다 | | | |
| 공유 링크 생성 후 새 탭에서 열기 | 같은 일정이 그대로 복원된다 | | | |
| 구간별 지도 앱 길찾기 링크 클릭 | 해당 구간 길찾기 화면이 열린다 | | | |
| 장소별 "가기 전 확인할 것" | 쉬는 날·영업시간·주차·예약·문의처가 표시된다 | | | |
| 휴대전화 폭 360px | 가로 스크롤 없이 모두 보인다 | | | |
| 키보드만으로 조작(Tab, Enter, 위·아래 버튼) | 초점이 보이고 순서 변경까지 가능하다 | | | |
| 출발지·도착지를 이름으로 검색(예: 서울역, 강남역) | 검색 결과 목록이 나오고 하나를 선택할 수 있다 | | | |
| 대중교통, 평일 낮 시각 vs 같은 일정의 심야 시각 | 시각에 따라 이동시간이 달라진다 | | | |
| 대중교통 구간 카드 | 소요시간, 노선 칩, 승·하차 정류장, 탑승 시간, 정류장 수, 배차 간격이 표시된다(환승이면 탑승이 여러 개) | | | |
| 배차 간격 정보가 없는 노선 | "배차 간격 정보 없음"으로 표시되고 오류가 나지 않는다 | | | |
| 자동차 선택 후 검사 | 구간별 거리와 소요시간이 표시된다 | | | |
| 날짜를 1년 뒤로 설정(대중교통) | 날짜 범위 안내가 나오고 날짜 칸으로 초점이 간다 | | | |
| 대중교통이 닿지 않는 곳(섬 등)을 포함 | "경로를 찾지 못했습니다" 안내와 할 일이 나온다 | | | |
| 서버·인터넷 연결 끊김 | 연결 오류 안내와 "다시 시도" 버튼이 나온다 | | | |
| 같은 일정을 연속 두 번 검사 | 두 번째가 더 빠르고(캐시), 결과는 같다 | | | |
